# 🎓 Portal Ujian Pendidikan Fisika UNM

Portal ujian online dengan **Multi-Device Realtime Monitoring** untuk Program Studi Pendidikan Fisika, Universitas Negeri Makassar.

## ✨ Fitur Utama

- 🔐 **Multi-Role Login** (Admin, Dosen, Mahasiswa)
- 📧 **Verifikasi OTP** via Email
- 🔥 **Firebase Realtime** — Sinkronisasi cloud
- 📱 **Multi-Device Sync** — Buka dari HP, laptop, tablet
- 🔴 **Live Monitoring** — Dosen pantau aktivitas mahasiswa realtime
- 🚫 **Anti-Paste** — Blokir copy-paste jawaban
- 🤖 **Deteksi AI** — Analisis pola konten AI
- 📋 **Rubrik Penilaian** — 3 aspek × skor 0-5
- 📊 **Database Nilai** — Filter, CSV export
- 🔗 **QR Pairing** — Hubungkan device cepat
- 📴 **Offline Queue** — Tetap simpan saat offline
